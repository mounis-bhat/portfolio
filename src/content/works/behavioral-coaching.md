## Overview

A full-stack application exploring AI-assisted behavioral coaching. The backend is written in Go using Google Genkit for the AI layer, with PostgreSQL for persistence and Valkey for caching; the front end is a SvelteKit SPA built with Svelte 5 and Tailwind CSS 4.

## Tech

- **Backend:** Go 1.25+, Google Genkit, PostgreSQL 17, Valkey
- **Frontend:** SvelteKit (SPA mode), Svelte 5, Tailwind CSS 4, TypeScript
- **Tooling:** goose migrations, sqlc, Air hot reload, Bun
